# Feature Status

**Last Updated:** 2026-10-15 (App Icons window titles setting; inventory lock warning fix)

## Status Legend

| Token | Meaning |
|-------|---------|
| `prod` | Live, verified, monitored. Real users. |
| `beta` | Feature-complete, under verification. Usable but not trusted. |
| `dev` | In development. Not verifiable end-to-end. |
| `stub` | Scaffold only. Returns placeholder. Not real. |
| `deprecated` | Still present, scheduled for removal. Do not build on. |

## Features

| Feature | Status | Description | Dependencies | Known Limitations | Location |
|---------|--------|-------------|--------------|-------------------|----------|
| Switcher keyboard | dev | Option+Tab arms, Option+Shift+Tab goes backward, arrows move, Return or Option release focuses, Esc cancels; selection wraps. Pure state machine with unit tests. | None | Not yet hand-tested in the running app. Also handles outside click, item click, hover and in-place removal events. | Sources/TabbyCore/SwitcherStateMachine.swift |
| Event tap | dev | Session key and mouse-button tap on its own thread; swallows Option+Tab and keys while open, swallows a click outside the open panel (and its mouse-up) so it does not reach the app underneath, re-enables after a system timeout, polls modifier state every 25 ms while open. | CoreGraphics, Accessibility | Does nothing while secure input is on. Cmd+Tab is untouched. | Sources/Tabby/KeyEventTap.swift |
| Switcher panel | dev | Non-activating panel on the screen with the mouse, shown after a 100 ms delay. Draws Titles, App Icons or Thumbnails layouts; the selected item has a filled, outlined highlight; titles truncate. | AppKit | Not yet hand-tested. Settings changes apply at the next open. | Sources/Tabby/SwitcherPanel.swift, Sources/Tabby/SwitcherItemViews.swift |
| Window inventory | dev | Background cache of windows on all Spaces, minimized and hidden apps via ScreenCaptureKit, merged with Accessibility minimized flags. Refreshed on app, Space, hide and AX window events plus a 3 s timer; the Option+Tab path only reads the cache. | ScreenCaptureKit, Accessibility | Needs Screen Recording; without it falls back to current-Space CoreGraphics. Minimized windows on other Spaces show as other desktop. Ordered-out helper windows on no Space, or only on currently visible Spaces, are dropped via private SkyLight lookups (window Spaces, per-display current Space); if missing they show as other desktop. | Sources/Tabby/WindowInventory.swift |
| Inventory rules | dev | Pure filter and merge: layer 0, at least 40 px, regular apps, not Tabby, untitled off-screen junk dropped, hidden-apps list, show-minimized and show-other-desktops toggles. Unit tested. | None | Also covers the show-hidden-apps toggle. | Sources/TabbyCore/WindowInventoryRules.swift |
| MRU ordering | dev | Pure most-recently-used order, seeded from z-order at launch, updated by app activation and AX focus events; closed windows drop out. Unit tested. | NSWorkspace, Accessibility | Focus changes need Accessibility; windows never focused keep inventory order after known ones. | Sources/TabbyCore/MRUOrder.swift |
| Row markers | dev | Rows show Minimized or Other desktop tags. | AppKit | Hidden-app windows get no tag. | Sources/Tabby/SwitcherPanel.swift |
| Private API shim | dev | Four private symbols resolved with dlsym at launch; menu status notes basic focus if any is missing. | SkyLight, HIServices | Behaviour on macOS 26 not yet hand-verified. | Sources/Tabby/PrivateAPI.swift |
| Window focus | dev | Unminimizes via Accessibility when reachable, brings the window forward across Spaces with SkyLight, then AXRaise. Falls back to activate plus AXRaise. | Accessibility, SkyLight | Not yet hand-tested; off-Space windows cannot be unminimized via AX. | Sources/Tabby/WindowFocuser.swift |
| Permissions onboarding | dev | First-run window shows Accessibility and Screen Recording status with buttons to the right System Settings pane; polling continues after launch and the key tap starts once Accessibility is granted. | Accessibility, ScreenCaptureKit | Without Screen Recording the switcher shows app icons only. | Sources/Tabby/Permissions.swift |
| Menu bar item | dev | Status item with a live status line, Permissions, Settings and Quit. | AppKit | None known. | Sources/Tabby/AppDelegate.swift |
| Persistent settings | dev | Codable settings with defaults; missing keys, unknown layout or thumbnail size and bad data fall back safely; older saved data still decodes. | Foundation | Fresh installs default to Thumbnails; a saved layout is kept. | Sources/TabbyCore/Settings.swift |
| No-network guard | dev | A unit test scans Sources/ and fails if any networking API name appears. | swift-testing | Name-based scan; cannot catch obfuscated use. | Tests/TabbyCoreTests/NoNetworkTests.swift |
| App bundling | dev | scripts/bundle.sh builds Tabby.app signed with "Flameshot Local"; --install copies to /Applications and relaunches. | codesign | Fails if the signing identity is missing. | scripts/bundle.sh |
| Settings window | dev | Menu item Settings... (Cmd+,) opens a SwiftUI form: layout, thumbnail size, live preview, show minimized / other desktops / hidden apps' windows, hidden-apps list picked from running apps, launch at login. Changes save and apply live. | AppKit, SwiftUI, ServiceManagement | Thumbnail size applies to the Thumbnails layout; Show window titles to App Icons (default on). Launch at login needs the app in /Applications. Not hand-tested. | Sources/Tabby/SettingsWindow.swift |
| Thumbnails | dev | ScreenCaptureKit capture when a window loses focus plus a refresh of on-screen windows on open; async, max 4 at once, sized from the thumbnail-size setting. Cached or app-icon image shows first, captures swap in. | ScreenCaptureKit, Screen Recording | Not yet hand-tested. Only on-screen windows are captured; minimized and other-desktop windows keep their last image or the app icon. | Sources/Tabby/ThumbnailStore.swift |
| Thumbnail cache | dev | Pure LRU with a 64 MB byte budget, eviction on window close, and a trust rule: a capture taken while off-screen never replaces a cached image. Unit tested. | None | Entries cost width x height x 4 bytes. | Sources/TabbyCore/ThumbnailCache.swift |
| Layouts and auto size | dev | Titles, App Icons and Thumbnails layouts. App Icons can show the window title (two lines) under each icon; the tile grows to fit. Panel fits its content, wraps balanced rows, caps at 90% of the pointer screen and scrolls rows around the selection. Pure math, unit tested. | None | Not yet hand-tested on multiple screens. | Sources/TabbyCore/PanelGeometry.swift |
| Mouse selection | dev | Click an item to focus it and close the switcher (works while Option is held). Click outside the panel cancels. Hovering selects the item once the pointer really moves. | CoreGraphics, AppKit | Not yet hand-tested. Only left and right buttons are watched. | Sources/Tabby/SwitcherEngine.swift, Sources/Tabby/SwitcherPanel.swift |
| Hover controls | dev | Close, minimize or restore, full screen on the hovered item via Accessibility, drawn as macOS-style traffic lights at the top-left (glyphs on hover); gray quit-app button at the top-right. The list updates in place and the selection moves to the item that took its place. Hidden for windows without an AX element. | Accessibility | Not yet hand-tested. Close and quit are optimistic: the item leaves the list even if the app shows a save prompt. Full screen leaves the item in place. | Sources/Tabby/WindowControls.swift, Sources/TabbyCore/SelectionIndex.swift |
| Live preview | dev | When enabled, outlines the selected window's on-screen frame and lightly dims other screens. Click-through overlay below the panel; the real window is never raised. No outline for minimized, other-desktop or hidden windows. | AppKit | Not yet hand-tested. Setting changes apply at the next selection. Single-screen setups get outline only. | Sources/Tabby/PreviewOverlay.swift, Sources/TabbyCore/PreviewRules.swift |
